# AIX 홍대 운영툴 — 시간표 편성 · 강사 배정

구글시트로 하던 시간표 편성과 강사 배정을 웹으로 옮긴 도구입니다.

- **화면**: GitHub Pages (무료 웹 호스팅)
- **로그인·데이터 저장**: Firebase (구글 무료 서비스 — 구글 계정 로그인 + 실시간 공유 저장)

> 설정 전에 `index.html`을 열면 **데모 모드**로 열립니다. 가상 예시 데이터가 들어 있고, 수정 내용은 그 브라우저에만 저장됩니다.
>
> ⚠️ 저장소가 Public이라 **코드 안에 실제 강사명·시간표를 넣지 마세요.** 실제 데이터는 로그인 후 화면에서 입력하면 Firebase에만 저장됩니다.

---

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀과 디자인 |
| `app.js` | 기능 전체 (시간표, 강사 집계, 설정, 사용자 관리) |
| `firebase-config.js` | **직접 채워야 하는 설정값** (Firebase 연결 정보, 최초 관리자 메일) |
| `firestore.rules` | 접근 규칙 (누가 읽고 쓸 수 있는지) — Firebase 콘솔에 붙여넣기 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리게 하는 빈 파일 (지우지 마세요) |

## 처음 한 번만 하는 설정 (약 15~20분)

### 1. GitHub 저장소 만들고 파일 올리기
1. github.com → 오른쪽 위 **+** → **New repository**
2. 이름 예: `aix-timetable` → **Public** 선택 → Create
   - Public이어도 **코드만 보이고 시간표 데이터는 보이지 않습니다.** 데이터는 Firebase에 있고, 4단계 규칙으로 등록된 사람만 읽을 수 있습니다.
3. **Add file → Upload files** → 이 폴더의 파일 5개를 모두 끌어다 놓고 **Commit changes**

### 2. Firebase 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가** → 이름 예: `aix-timetable` → (Google 애널리틱스는 꺼도 됨) → 만들기
2. 프로젝트 첫 화면에서 **웹 아이콘 `</>`** 클릭 → 앱 이름 입력(예: 시간표) → **앱 등록** (Hosting 체크는 하지 않음)
3. 화면에 나오는 `firebaseConfig = { apiKey: ..., ... }` 값 6개를 복사해 둡니다.

### 3. 구글 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication** → 시작하기
2. **Sign-in method** 탭 → **Google** → 사용 설정 → 지원 이메일 선택 → 저장
3. **Settings(설정)** 탭 → **승인된 도메인** → **도메인 추가** → `내깃허브아이디.github.io` 입력

### 4. 데이터베이스 만들고 규칙 넣기
1. 왼쪽 메뉴 **빌드 → Firestore Database** → 데이터베이스 만들기
2. 위치: **asia-northeast3 (서울)** → **프로덕션 모드**로 시작
3. 만들어지면 **규칙** 탭 → 기존 내용을 지우고 `firestore.rules` 내용을 통째로 붙여넣기
4. 그 안의 `'여기에-관리자-구글메일@gmail.com'`을 **내 구글 메일(소문자)** 로 바꾸고 **게시**

### 5. 설정 파일 채우기
GitHub 저장소에서 `firebase-config.js` 클릭 → 연필(✏️) 아이콘 → 아래처럼 채우고 **Commit changes**

```js
window.APP_CONFIG = {
  ownerEmails: ['내메일@gmail.com'],          // 4단계 규칙에 넣은 메일과 똑같이
  firebase: {
    apiKey: '2단계에서 복사한 값',
    authDomain: '...',
    projectId: '...',
    storageBucket: '...',
    messagingSenderId: '...',
    appId: '...'
  }
};
```
> apiKey가 공개돼도 괜찮습니다. Firebase 웹 설정값은 원래 공개용이고, 실제 보안은 4단계 규칙이 담당합니다.

### 6. GitHub Pages 켜기
1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch** → Branch: **main** / **/(root)** → Save
3. 1~2분 뒤 위쪽에 나오는 주소(`https://내아이디.github.io/aix-timetable/`)로 접속

### 7. 첫 로그인과 사용자 등록
1. 주소 접속 → **Google 계정으로 로그인** (관리자 메일로)
2. **+ 새 달 만들기** → 시작 방법 **'빈 시간표'** 선택 후 실제 수업 입력
3. **사용자 관리** 탭 → 함께 쓸 사람의 구글 메일 등록 → 권한 선택

| 권한 | 할 수 있는 일 |
|---|---|
| 열람 | 시간표·강사 집계 보기 |
| 편집 | + 수업 추가·수정·삭제, 새 달 만들기, 시간표 설정 |
| 관리자 | + 사용자 등록·권한 변경, 달 삭제 |

등록되지 않은 사람은 로그인해도 "접근 권한이 없습니다" 화면만 보입니다.

## 매달 쓰는 방법

1. 위쪽 **+ 새 달 만들기** → 만들 달 선택 → **지난달 복사** (기본값)
2. 바뀐 수업만 수정 — **빈 칸 클릭 = 추가**, **수업 클릭 = 수정·삭제**
3. 위쪽 **확인 필요** 박스에서 칸 겹침 · 강사 중복 · 강사 미배정을 확인
4. **강사별 집계** 탭에서 강사별 타임·과목 수 확인 → 필요하면 **CSV 내려받기**

### 수업 입력 규칙
- **요일**: 월/수 · 화/목 · 월~목(월수+화목 합친 칸) · 금. 주말은 기본 '토일' 한 칸
- **강의실**: 기본 A~S + 비대면 (설정에서 변경 가능)
- **수업시간(H)**: 시작 시간부터 몇 시간인지. 18:00에 2H면 19:00 줄까지 자동으로 합쳐 보입니다 (예: 웹툰 18:00 4H → 18·19·20시 줄)
- **강사**: 이름 뒤 숫자까지 정확히 (홍길동1 ≠ 홍길동2). 두 명이면 `홍길동1/김철수`. `공강`은 집계에서 빠짐
- **강사 없는 칸**(자습실 등)은 체크하면 '미배정' 경고가 뜨지 않음

### 강사별 집계 기준
- **타임** = 수업 1회 시간 합계 (1시간 = 1타임). 월수 18:00 2H 수업 하나 = 2타임
- **주간 시간** = 타임 × 주당 수업일수 (월/수 = 2일, 월~목 = 4일, 금 = 1일, 토일 = 2일)
- **담당 과목 수** = 과목명을 `/`로 나눠 중복 없이 셈 (유툽/AI유툽 → 2과목, 괄호 안 `/`는 안 나눔)

### 시간표 설정 (편집 권한)
시간대, 기본 수업시간, 강의실 목록, 요일 묶음을 **달마다** 바꿀 수 있습니다.
- 주말을 토·일 따로 편성: 요일 묶음을 `토(1일)`, `일(1일)` 두 개로
- 주말 1일 수업만 있는 달: `토(1일)` 하나로
- 요일 묶음을 바꾸면 '수업 팝업의 요일 선택 항목'도 같이 맞춰 주세요. 형식: `표시이름=요일묶음` (예: `월~목=월수+화목`, `토=토`)
- 설정에서 지운 시간·강의실에 있던 수업은 삭제되지 않고 '배치 안 됨'에 표시됩니다.
